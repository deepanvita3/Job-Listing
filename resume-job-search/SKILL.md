# Resume Job Search

Find ten distinct, current openings that are well matched to the user's resume. Search LinkedIn, Indeed, and official technology-company careers pages. Use live web search and link to the individual job posting wherever possible.

## Gather the search brief

Ask for the resume file if it is not attached or otherwise available. Extract the candidate's recent titles, responsibilities, skills, seniority, total and relevant experience, industry/domain background, education or required credentials, and work authorization only when stated in the resume.

Always ask for location before searching unless the user has already stated it clearly. Clarify only information that would materially alter the results; do not guess. Examples include whether remote, hybrid, or relocation roles are acceptable; a broad or conflicting target role; whether a required work authorization or clearance is unknown; a role-level mismatch; or an unclear geographic scope. Ask concise questions together before searching rather than silently applying assumptions.

If the resume cannot be read, say what failed and ask for a readable PDF, DOCX, or pasted text. Treat the resume as sensitive: use it only for this job search and avoid reproducing unnecessary personal details in the results.

## Search and assess

Search each of these source types:

- LinkedIn Jobs
- Indeed
- Official careers pages of relevant technology companies

Use search results only to discover opportunities. Before counting a job as an eligible candidate or recommending it, open its direct posting and verify that it is actively accepting applications on the date checked. A job passes only when the live page provides an active application path and does not indicate that applications are closed, the requisition is no longer available, or the job has expired.

Treat cached search snippets, reposted aggregator pages, and LinkedIn login/auth-wall pages as discovery evidence only—not proof that the job is still open. Prefer the employer's official careers page for the final check. When an official page conflicts with another source, use the official page and exclude a closed requisition. If the active application state cannot be verified, omit the job from the final list and do not count it toward the 100-opening pool.

Deduplicate the same employer and requisition across sources; use the official company posting as the primary link when it is available. If a source is unavailable or cannot be verified, state that limitation and continue with the available sources.

Before choosing the top ten, evaluate a pool of at least 100 distinct, current openings that satisfy the user's stated filters. Remove duplicates and roles that fail a known hard requirement before ranking. If fewer than 100 eligible, verifiable openings can be found, report the shortfall and its cause rather than treating the smaller pool as a 100-job search.

Evaluate each position against the resume, giving greatest weight to role/title fit, directly relevant skills, and the demonstrated experience level. Also consider domain experience, location/work arrangement, and explicit required qualifications. Do not count a keyword-only match as strong evidence. Exclude roles with a clear hard mismatch unless the user asked for stretch opportunities.

## Deliver the results

Return exactly ten distinct opportunities when ten verifiable suitable openings exist. Rank them best-first and, for each, include:

- Job title, company, location, and work arrangement if stated
- A direct posting link and source, with the application status confirmed on the date checked
- A concise, resume-specific reason it matches: title/role alignment, relevant skills, and experience/seniority alignment
- Material gaps or requirements to check, clearly labeled

Briefly state the filters used and the date checked. If fewer than ten verified fits exist, return the verified set and explain which constraint prevented a full ten; ask whether the user wants the search broadened. Never invent job details, application deadlines, compensation, or qualifications that are not on the listing.
